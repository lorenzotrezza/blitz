## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser sessionStorage -> ResultsPage | Stored result payload can be missing, stale, corrupt, or partial. |
| server result payload -> browser summary | Browser formats display fields but must not compute authoritative outcomes. |
| ResultsPage -> post-game socket actions | UI changes must not weaken existing host-only post-game flow. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10 | Repudiation | `ResultsPage` stored payload handling | mitigate | Normalize/catch stored payloads; partial summary helpers return null while rankings remain visible. |
| T-06-11 | Tampering | browser result summary calculation | mitigate | Summary helpers only format server-provided `summary`, `details`, `label`, or `value` fields; no browser-side outcome computation. |
| T-06-12 | Elevation of Privilege | post-game controls after summary insertion | mitigate | Tests keep host/non-host post-game controls intact; server host checks are covered in Plan 05. |
</threat_model>
