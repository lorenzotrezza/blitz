## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser->shared types | Browser code imports shared contracts, but TypeScript does not make packets trustworthy at runtime. |
| browser->Socket.IO `client:game-input` | Untrusted clients can forge arbitrary input payloads crossing into server runtimes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `DragGearInput`, `GameInputPayload` | mitigate | Shared input contracts contain throttle/shift intent only; no client fields for speed, RPM, distance, finish time, ranking, or summary are added. |
| T-02-02 | Denial of Service / Tampering | `DragGearInput.sequence` | mitigate | Contracts include `sequence` and discriminants so server rules can clamp malformed packets and ignore repeated shift actions in later plans. |
