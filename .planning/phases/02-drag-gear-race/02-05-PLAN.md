<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser controls->Socket.IO `client:game-input` | Physical controls become untrusted throttle/shift intent. |
| Socket.IO session state->React route | Server snapshot controls what the HUD and track render. |
| browser lifecycle->server throttle state | Cancel, blur, visibility, unmount, finish, and disconnect must not leave throttle pressed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `DragGearRacePage` submitInput mapping | mitigate | Page emits only `drag-throttle` and `drag-shift` intent; it never sends speed, RPM, finish time, rankings, or summary. |
| T-02-02 | Denial of Service / Tampering | `DragGearRacePage` shift control | mitigate | Shift is emitted as a discrete action; repeated keydown is ignored by tests and server-side sequence guards handle spam. |
| T-02-03 | Tampering / Reliability | `DragGearRacePage` throttle lifecycle | mitigate | Tests and implementation release throttle on pointer cancel, blur, visibility hidden, route unmount, race finish, and connection loss. |
</threat_model>
