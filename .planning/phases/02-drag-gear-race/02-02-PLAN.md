## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `scoreShift`, `advanceDragGearPlayer` | mitigate | Score shifts from server `rpm` and derive speed, distance, finish time, rankings, and summary on the server; do not use `clientTimeMs` as authoritative physics time. |
| T-02-02 | Denial of Service / Tampering | `readDragGearInput`, `applyDragGearInput` | mitigate | Reject malformed input, ignore non-racing inputs, ignore repeated sequence values, and ignore invalid gear transitions above gear 4. |
| T-02-03 | Tampering / Reliability | server throttle state | mitigate | Server accepts explicit throttle release input and runtime remove/dispose paths in Plan 03 clear active players; client reset paths are implemented in Plan 05. |
