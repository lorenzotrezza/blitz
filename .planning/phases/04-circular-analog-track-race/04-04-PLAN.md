<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser controls -> socket input | Pointer/keyboard state is converted into untrusted analog intent. |
| server snapshot -> canvas/HUD | Browser renders authoritative server state without changing it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `CircleTrackPage` input emission | mitigate | Emit only `RaceAnalogInput` from `useGameControls` with `modeId: circle`; server clamps and validates values. |
| T-04-02 | Denial of Service | analog input loop | mitigate | Use existing `useGameControls` event emission and compact payloads; do not add canvas-driven network emission or per-frame socket loops. |
| T-04-03 | Tampering | HUD/canvas state | mitigate | Render lap, gate, penalty, speed, finish, and direction from `CircleTrackSnapshot`; never compute or submit those fields from the client. |
</threat_model>
