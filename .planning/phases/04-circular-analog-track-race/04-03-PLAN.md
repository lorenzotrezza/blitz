## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| socket gateway -> runtime | `GameInputPayload` from an untrusted client reaches `applyInput()`. |
| runtime -> session results | Finish state and rankings affect lobby results and post-game navigation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `createCircleTrackRuntime().applyInput()` | mitigate | Require `isRaceGameInput`, `kind === analog`, `modeId === circle`, clamp vector through rules, and ignore malformed/non-circle input. |
| T-04-02 | Denial of Service | `applyInput()` and `emitState()` | mitigate | Apply constant-time rule helpers per input and avoid creating unbounded payloads; add input coalescing only if tests/manual play show snapshot flood. |
| T-04-03 | Tampering | runtime finish/checkpoint/result state | mitigate | Do not read lap/checkpoint/penalty/finish fields from input; derive those fields in `circleTrackRules.ts` and runtime state only. |
</threat_model>
