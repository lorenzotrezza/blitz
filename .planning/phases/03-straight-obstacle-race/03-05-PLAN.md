<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route params->session hook | URL session id selects which server session to display. |
| React controls->Socket.IO | Steering control emits untrusted client intent. |
| server snapshot->route render | Authoritative state becomes road/HUD text and result navigation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `StraightObstacleRacePage` steering submission | mitigate | Page submits only `StraightObstacleInput` from `useDodgeRaceControls`; server runtime clamps and validates independently. |
| T-03-02 | Tampering | `StraightObstacleRacePage` | mitigate | Page never computes or submits speed, distance, hit count, slowdown, finish, ranking, or result details; it only renders snapshots/results from server events. |
| T-03-03 | Denial of Service | `useDodgeRaceControls` integration | transfer | Page emits sequence-bearing intent; server runtime coalesces latest valid steering and ignores stale/flooded input. |
| T-03-04 | Information Disclosure / Accessibility | `StraightObstacleRacePage`, `DodgeHud` | mitigate | Route renders warning/slowdown/hit state as React text through `DodgeHud` with a polite live region. |
</threat_model>
