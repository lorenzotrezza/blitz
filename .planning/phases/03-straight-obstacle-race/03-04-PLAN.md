<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| physical input->React controls | Pointer and keyboard events become local steering intent. |
| React controls->Socket.IO input | Local steering state becomes untrusted `client:game-input` payload. |
| server snapshot->React HUD/road | Authoritative snapshot fields become visual road and status text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `useDodgeRaceControls`, `DodgeSteeringPad` | mitigate | Emit only normalized finite `steerX` intent in `-1..1`; server runtime still clamps independently. |
| T-03-02 | Tampering | `useDodgeRaceControls` emitted payload | mitigate | Emit only `mode`, `kind`, `steerX`, `sequence`, and `clientTimeMs`; never emit speed, distance, hit count, slowdown, finish, ranking, or result fields. |
| T-03-03 | Denial of Service | `useDodgeRaceControls` sequence emission | transfer | Client includes sequence; server runtime keeps latest valid intent and ignores stale/non-finite values. |
| T-03-04 | Information Disclosure / Accessibility | `DodgeHud` | mitigate | Render `Obstacle ahead`, `Hits`, `Speed`, `Distance`, `Slowdown`, and `Hit - recovering` as React text with `aria-live="polite"` for state changes. |
</threat_model>
